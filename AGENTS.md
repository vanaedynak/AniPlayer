# Anyflow Lab — правила для ИИ-агента

Это **лаборатория**: копия плеера Anyflow (аниме, манга, ранобэ) для экспериментов. Основной проект живёт
отдельно, и хозяин переносит туда из лаборатории только то, что получилось. Поэтому главное — не сломать
проект и держать изменения такими, чтобы их можно было перенести.

Отвечай по-русски. Тексты в интерфейсе — по-русски, комментарии в коде — по-английски.

## Что где

- `app/` — само приложение: React 19 + TypeScript + Vite + Tailwind v4, состояние в Zustand (с сохранением).
  - `app/src/pages/` — экраны (главная, каталог, тайтл, плеер `Watch.tsx`, профиль, настройки…).
  - `app/src/components/` — общие куски интерфейса.
  - `app/src/lib/` — данные и логика: `api.ts` (AniLibria), `store.ts` (сохранённое состояние пользователя),
    `sync.ts` (облако), `shikimori.ts`, `anilist.ts`, `kodik.ts`, `torrent.ts`, `platform.ts` (ПК / iPad / браузер).
  - `app/src/manga/` — читалка манги, переводчик страниц через Gemini (`translate.ts`), свои файлы книг.
  - `app/src/ranobe/` — ранобэ; `app/src/read/` — книжные страницы, развороты, бумага, свет, звук.
  - `app/electron/` — оболочка для Windows (Electron). iPad и Android собираются через Capacitor в GitHub Actions.
  - `app/flavor.json` — имя и ID этой копии приложения. **Не трогать** (см. правила).
- `docs/` — сайт-лендинг. `.github/workflows/build.yml` — сборка IPA, APK и установщика Windows.
- `lab-tools/` — скрипты хозяина для обновления лаборатории из основного проекта. Не трогать.

## Команды (из папки `app`)

```
npm install                          # один раз и после смены package.json
npm run dev                          # приложение в браузере: http://localhost:5173
npm run electron:dev                 # окно приложения для Windows (свои данные лаборатории)
npx tsc -p tsconfig.app.json --noEmit  # проверка типов
npm run build                        # полная сборка; должна проходить перед каждым коммитом
```

Часть источников (Senkuro, RanobeHub) в браузере идёт через прокси Vite, а торренты и голос работают
только в приложении для Windows: проверяй такое через `npm run electron:dev`.

## Правила

1. **Не трогай основной проект.** Не открывай и не меняй `D:\Projects\AniPlayer`, никогда не пушь в
   `vanaedynak/AniPlayer` и в remote `upstream` (пуш туда отключён специально). Работаешь только здесь,
   пушишь только в `origin` (`vanaedynak/anyflow-lab`).
2. **Не меняй `app/flavor.json`.** Благодаря ему лаборатория ставится отдельным приложением «Anyflow Lab»
   со своими данными и не затирает основное приложение на ПК, iPad и Android.
3. **Аккаунт и облако общие с основным приложением.** Вход, закладки, история, планы хранятся в тех же
   Firebase и Supabase. Поэтому:
   - не пиши код, который удаляет или массово перезаписывает данные пользователя в облаке;
   - не запускай SQL, админские и CLI-команды Supabase/Firebase, не удаляй аккаунты и проекты;
   - `app/supabase/schema.sql` можно читать, но изменения в нём сами никуда не применяются — не рассчитывай на них;
   - ключей и паролей в репозитории нет и не должно быть: не добавляй их в код и не проси.
4. **Сохранённые данные — только совместимо.** Ключи localStorage и Zustand persist (`aniplayer-store` и
   другие) не переименовывай и формат не ломай: новые поля добавляй со значениями по умолчанию (через `merge`
   в persist). Иначе после переноса в основной проект у хозяина пропадут история и настройки.
5. **Маленькие, понятные изменения.** Не переформатируй целые файлы, не переименовывай и не переносишь файлы
   пачками, не обновляй мажорные версии пакетов, не запускай `npm audit fix --force`. Огромный дифф потом
   невозможно перенести. Prettier — только для новых файлов и только так:
   `npx prettier --single-quote --no-semi --print-width 180 --write <файл>`.
6. **Коммиты.** Перед коммитом — `npm run build` без ошибок. Один коммит — одна законченная вещь, сообщение
   по делу. Рискованный эксперимент — в отдельной ветке (`git switch -c try-<что>`), в `main` — когда работает.
   Пуш в `main` лаборатории запускает сборку IPA, APK и установщика Windows (вкладка Actions, затем Releases → latest).
7. **Источники.** Только открытые API, которые уже используются (AniLibria, Shikimori, AniList, MangaDex и т.п.).
   Не обходи защиту сайтов (DDoS-Guard, Cloudflare, проверки на ботов), не подделывай User-Agent, не добавляй
   пиратские сайты и трекеры, не вытаскивай прямые потоки из Kodik.
8. Не трогай `lab-tools/`, `AGENTS.md`, `GEMINI.md`, `.agent/` и workflow в `.github/`, если хозяин прямо не просит.
9. Если не уверен, что изменение безопасно, — спроси, а не делай.
